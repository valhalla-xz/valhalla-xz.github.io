# UNKO:

**Universal Nexus of Knowledge & Objects**

PCハードウェアの仕様・互換性情報を整理する静的サイトの初期版。

## ファイル構成

- `index.html` — ページ構造
- `style.css` — シンプルな表示スタイル
- `app.js` — 検索、絞り込み、並び替え、詳細表示
- `data.json` — パーツデータ

## GitHub Pagesで公開する

1. GitHubで新しいリポジトリを作成する。
2. このフォルダー内のファイルをリポジトリのルートにアップロードする。
3. リポジトリの **Settings → Pages** を開く。
4. 公開元として `Deploy from a branch` を選択する。
5. `main` ブランチの `/ (root)` を選んで保存する。

## ローカルで確認する

`fetch("./data.json")` を使用しているため、`index.html` をファイルとして直接開くとブラウザによってはデータを読み込めない。Pythonが入っている場合は、このフォルダーで次を実行して `http://localhost:8000` を開く。

```sh
python -m http.server 8000
```

## データ追加時の注意

`data.json` に同じ形式のオブジェクトを追加する。電力値は数値の `power_w` と、定義を示す `power_label` に分ける。TDP、PBP、MTP、PPT、TBP、TGPなどは意味が同一ではないため、同じ基準の数値として扱わないこと。

各パーツの公式出典URLを確認し、未確認データを確定情報として公開しない。互換性情報は、規格上の対応と実機検証済みの情報を区別する。

## 初期版の範囲

この版はフロントエンドの土台とサンプルデータ。完全な互換性判定、ユーザー投稿、サーバー側データベースは実装していない。
